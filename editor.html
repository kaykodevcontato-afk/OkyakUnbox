👽 OKYAK UNBOX

Editor de produtos — fotos, vídeos, título, descrição e afiliados

1. Carregue seu arquivo index.html

Este editor funciona no seu navegador. Por segurança, você precisa selecionar o index.html uma vez. Depois, edite os produtos e baixe o HTML atualizado. Nenhuma informação é enviada para servidores.

Abra o index.html que veio no ZIP para começar.

2. Produtos do catálogo

Carregue o HTML para ver os produtos.

3. Editar produto

Preencha fotos extras colocando uma imagem por linha. Deixe o vídeo vazio quando não tiver um unboxing.

Coloque suas imagens na pasta assets/ e envie junto ao GitHub.
Sem limite fixo de fotos. O visitante poderá passar pelas fotos com setas e miniaturas.
Se vazio, o botão de compra fica desativado.
Ao terminar, clique em Baixar index.html atualizado, substitua o index.html do site e publique no GitHub. Este editor não modifica o arquivo original automaticamente.
